# sensorMonitor_v1 — ESP-IDF / esp-matter build

Native ESP-IDF port of `../sensorMonitor_v1.ino`. Same hardware, pins, Matter endpoints
(1 = temperature, 2 = humidity, 3 = air quality + CO2/HCHO/TVOC/PM2.5/PM10), and screen layout.

| File | Replaces |
|---|---|
| `main/app_main.cpp` | `setup()`/`loop()`, Arduino `Matter`, `HardwareSerial`, `WiFi` |
| `main/epd.cpp/.h` | GxEPD2 (`GxEPD2_420_GDEY042T81` + `GxEPD2_BW`) + Adafruit GFX text |
| `main/ui.cpp/.h` | display cards, IAQI, change detection |
| `main/fonts/` | Adafruit GFX fonts (unchanged) |

esp-matter is pulled from the ESP component registry (`main/idf_component.yml`), so you only
need ESP-IDF installed (v5.5.x recommended, which matches Arduino core 3.3.11).

## Network: Matter over Thread

The device joins your Thread network (Apple TV 4K / HomePod mini as border router).
BLE is only used during pairing. Wi-Fi is disabled.

## Pairing data (factory partition)

Each device has its own passcode, discriminator and DAC in the `fctry` partition,
generated by `factory/gen_factory.sh` (needs `esp-matter-mfg-tool`, installed in the IDF venv).
The DAC is signed by the public Matter test PAI (VID 0xFFF1 / PID 0x8000), so Apple Home
shows an "uncertified accessory" warning but pairs fine.

`factory/out/` holds the device's private key and passcode and is git-ignored. Keep a backup:
if it is lost, generate new data and re-pair. `factory/out/qrcode.png` is a printable label.

While unpaired, the e-paper shows the QR code and manual code.

## Build & flash

```sh
source ~/.espressif/tools/activate_idf_v5.5.6.sh   # or use the VS Code ESP-IDF extension
cd idf
./factory/gen_factory.sh       # once per device
idf.py set-target esp32c6      # first time only
idf.py build
idf.py -p /dev/ttyACM0 erase-flash flash monitor   # flash also writes factory/out/fctry.bin
```

Hold BOOT for 5 s to factory reset (the fctry partition is kept, so the QR code stays the same).
Removing the device from the last controller also factory resets it.
